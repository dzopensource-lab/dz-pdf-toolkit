# 📄 DZ PDF Toolkit v1.0.0 (Windows)

**First official release (v1.0.0)** of **DZ PDF Toolkit** — a free, open-source, and **100% offline** PDF desktop utility for Windows designed to process your documents locally with complete privacy.

**Première version officielle (v1.0.0)** de **DZ PDF Toolkit** — une boîte à outils PDF gratuite, open-source et **100 % hors-ligne** conçue pour manipuler vos documents rapidement en toute confidentialité.

## ✨ Features | Fonctionnalités

* **🔗 Merge / Fusionner:** Assemble multiple PDF files into one document with page reordering / Assemblez plusieurs fichiers PDF en un seul document avec réorganisation des pages.
* **✂️ Split / Diviser:** Extract a specific range of pages into a new independent PDF file / Extrayez une plage précise de pages dans un nouveau fichier PDF indépendant.
* **🔄 Rotate / Pivoter:** Fix page orientation (`90°`, `180°`, or `270°`) / Corrigez l'orientation des pages (`90°`, `180°` ou `270°`).
* **🗜️ Compress & Protect / Compresser & Protéger:** Reduce file size and secure documents with a password / Réduisez la taille des fichiers et sécurisez-les par un mot de passe.
* **🌐 Bilingual Interface / Interface Bilingue:** Instantly switch between **Français** and **English** / Basculez instantanément entre le **Français** et l'**Anglais**.
* **⚡ Portable & Standalone / Portable & Autonome:** No installation or Python required / Aucune installation ni Python requis.

## 📥 Download & Installation | Téléchargement & Installation

1. Go to the **[Releases](https://github.com/dzopensource-lab/dz-pdf-toolkit/releases)** section. / Allez dans la section **[Releases](https://github.com/dzopensource-lab/dz-pdf-toolkit/releases)**.
2. Download **`DZ-PDF-Toolkit.exe`** / Téléchargez **`DZ-PDF-Toolkit.exe`**.
3. Run it directly (Portable version for Windows 10/11 64-bit) / Lancez-le directement (version portable pour Windows 10/11 64-bit).

> **💡 Windows SmartScreen Note / Note Windows SmartScreen :** Since this is an unsigned open-source release, Windows might show a warning. Click **"More info"** then **"Run anyway"** / Comme il s'agit d'une version open-source non signée, Windows peut afficher un avertissement. Cliquez sur **"Informations complémentaires"** puis **"Exécuter quand même"**.
